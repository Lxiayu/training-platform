# training-platform

编程培训管理平台（启航编程管理系统）—— 面向中小型编程培训机构的一站式管理平台：学员、课程、班级排课、教师、缴费与统计。

## 当前阶段：第三阶段 · 前后端一体化（v0.3）

在第二阶段后端的基础上，前端已从 localStorage 演示数据全面切换为调用 `/api/v1` 后端接口：

- **框架**：FastAPI + uvicorn（依赖见 `pyproject.toml`），分层架构 `api（路由）→ services（业务）→ db（存储）`；
- **存储**：`data/app.json` 单文件暂存（首次启动自动写入种子数据，并按需生成密码哈希），文件级锁 + 事务保证并发写安全；后续按《技术栈规划》平滑切换 MySQL + Redis；
- **认证**：JWT（`Authorization: Bearer <token>`），密码 PBKDF2-SHA256 加盐哈希；用户管理仅超级管理员可用；
- **API 前缀**：`/api/v1`，统一响应壳 `{code: 0, message, data}`，业务异常返回中文提示（400/401/403/404/409）；
- **前端接入**（本阶段新增）：
  - `web/js/api.js`：统一 API 客户端 —— Bearer 注入、响应壳解析、401 自动清理会话并跳登录、全量资源方法（CRUD + 缴费确认/作废、新闻阅读、资源下载、工作台统计、系统设置）；
  - `web/js/common.js`：`boot()` 页面启动入口（布局渲染 + 会话校验）+ `hydrate()` 全量缓存拉取；写操作成功后重新 `hydrate()`，本地视图与服务器始终一致；
  - 登录支持「记住我」（localStorage 持久会话 / sessionStorage 会话级）；
  - 普通用户可在「个人信息」页自助修改姓名/手机/邮箱（`PUT /auth/profile`）与密码；用户列表仅管理员拉取，非管理员访问相关接口返回 403；
  - 「系统设置」的演示数据重置改为调用 `POST /settings/reset`（服务端全量恢复种子状态），非管理员只读。
- **业务规则**（与设计文档一致，均有验证脚本覆盖）：
  - 取号规则 `JS/KC/BJ/XS/JF/XW/ZY + 3 位序号`，软删后不复用；
  - 删除保护：教师被班级引用、课程被班级引用、班级有学员时禁止删除；
  - 开班校验：停售课程不可开班、离职教师不可排课；
  - 缴费状态机：待确认 → 已支付 / 已作废（已退款为终态），收入统计仅计「已支付」；
  - 学员删除时级联归档其名下缴费记录（同一事务）；
  - 系统至少保留一个启用的超级管理员，不能删除/禁用/降级自己。

### 技术说明

- 数据全部来自 `/api/v1` 后端（`web/js/api.js` 统一封装请求与 token 会话）；
- 页面通过 `boot(pageKey)` 启动：同步渲染布局校验会话，再 `hydrate()` 并行拉取全部集合到 `window.DB` 缓存，写操作成功后重新拉取，保证与服务器一致；
- 会话：JWT token + 用户信息，按「记住我」选择存 localStorage（持久）或 sessionStorage（关闭浏览器失效）；token 过期后任意请求触发 401，自动清理会话并跳转登录页；
- 「系统设置 → 演示数据管理」调用后端一键重置（服务端恢复种子状态）；
- 通用组件（侧边栏布局、模态框、Toast、确认框、徽章、头像、权限过滤）由 `web/js/common.js` 提供。
