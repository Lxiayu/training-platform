# training-platform

编程培训管理平台（启航编程管理系统）—— 面向中小型编程培训机构的一站式管理平台：学员、课程、班级排课、教师、缴费与统计。

## 当前阶段：第一阶段 · 纯静态页面

由 **HTML + CSS + 原生 JavaScript** 实现，不依赖任何外部框架或 CDN，直接用浏览器打开即可运行。

### 功能模块

| 模块 | 说明 |
| --- | --- |
| 登录页 | 多角色演示账号（见下表），禁用账号无法登录 |
| 工作台 | 统计卡片、班级报名热度图、近期开班、最近缴费、快捷入口（按角色显示） |
| 课程管理 | 课程列表、搜索筛选、新增/编辑/删除、上架/停售 |
| 班级管理 | 排班（关联课程与教师）、报名进度条、状态管理 |
| 教师管理 | 教师档案、科目/状态筛选、在职/离职 |
| 学生管理 | 学员档案、班级关联、家长联系方式、在读/休学/已结课 |
| 缴费管理 | 收入统计、缴费登记（选学员自动带出班级与价格）、确认到账、作废 |
| 新闻中心 | 机构资讯门户：置顶头条、分类筛选、新闻详情（自动累计阅读量）、发布/编辑/删除 |
| 课件资源 | 资源库卡片：课件 PPT / 教学视频 / 习题册 / 素材包四类，按课程筛选、模拟下载计数、上传/编辑/删除 |
| 用户管理 | **仅超级管理员可见**：系统账号增删改、角色分配、启用/禁用、重置密码 |
| 个人信息 | 资料维护、修改密码 |
| 系统设置 | 机构信息、业务开关、一键重置演示数据 |

### 使用方式

```bash
# 方式一：直接双击打开
web/login.html

# 方式二：本地静态服务器（可选）
python -m http.server 8080 -d web
# 浏览器访问 http://localhost:8080
```

### 技术说明

- 演示数据硬编码在 `web/js/data.js`，首次加载后持久化于浏览器 localStorage，增删改操作刷新不丢失；
- 旧版本数据自动迁移（`meta.version` 比对）：升级到 v0.2 后会自动补齐多用户、新闻、课件资源数据，保留已有修改；
- 可在「系统设置 → 演示数据管理」中一键重置；
- 通用组件（侧边栏布局、模态框、Toast、确认框、徽章、头像、权限过滤）由 `web/js/common.js` 提供；
- 数据模型与业务校验（如：课程被班级引用时不可删除）为后续接入真实后端预留。
