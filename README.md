# training-platform

编程培训管理平台（启航编程管理系统）—— 面向中小型编程培训机构的一站式管理平台：学员、课程、班级排课、教师、缴费与统计。

## 当前阶段：第二阶段 · FastAPI 后端（JSON 文件暂存）

在保留纯静态前端（见下节）的基础上，交付了完整的后端服务：

- **框架**：FastAPI + uvicorn（依赖见 `pyproject.toml`），分层架构 `api（路由）→ services（业务）→ db（存储）`；
- **存储**：`data/app.json` 单文件暂存（首次启动自动写入与前端一致的种子数据，并按需生成密码哈希），文件级锁 + 事务保证并发写安全；后续按《技术栈规划》平滑切换 MySQL + Redis；
- **认证**：JWT（`Authorization: Bearer <token>`），密码 PBKDF2-SHA256 加盐哈希；用户管理仅超级管理员可用；
- **API 前缀**：`/api/v1`，统一响应壳 `{code: 0, message, data}`，业务异常返回中文提示（400/401/403/404/409）；
- **业务规则**（与设计文档一致，均有验证脚本覆盖）：
  - 取号规则 `JS/KC/BJ/XS/JF/XW/ZY + 3 位序号`，软删后不复用；
  - 删除保护：教师被班级引用、课程被班级引用、班级有学员时禁止删除；
  - 开班校验：停售课程不可开班、离职教师不可排课；
  - 缴费状态机：待确认 → 已支付 / 已作废（已退款为终态），收入统计仅计「已支付」；
  - 学员删除时级联归档其名下缴费记录（同一事务）；
  - 系统至少保留一个启用的超级管理员，不能删除/禁用/降级自己。

### 快速启动

```bash
python -m uvicorn app.main:app --reload --port 8000
# 浏览器访问 http://127.0.0.1:8000 （自动跳转登录页，静态前端与 API 同源部署）
# 交互式 API 文档：http://127.0.0.1:8000/docs
```

登录账号与第一阶段一致（`admin / admin123`、`jiaowu / 123456` 等，见下表）。

> 注意：第二阶段后端与第一阶段的 localStorage 数据相互独立——静态页面当前仍读取 `web/js/data.js` 演示数据，前后端接口对接为下一阶段工作。

### 后端验证脚本

```bash
python scripts/verify_api.py
```

使用隔离的临时数据文件跑 **79 项冒烟断言**（认证/权限、用户保护、删除保护、状态机、统计口径、排序、设置联动等），不污染 `data/app.json`。

## 第一阶段 · 纯静态页面

由 **HTML + CSS + 原生 JavaScript** 实现，不依赖任何外部框架或 CDN，直接用浏览器打开即可运行。

### 功能模块

| 模块 | 说明 |
| --- | --- |
| 登录页 | 多角色演示账号（见下表），禁用账号无法登录 |
| 工作台 | 统计卡片、班级报名热度图、近期开班、最近缴费、快捷入口（按角色显示） |
| 课程管理 | 课程列表、搜索筛选、新增/编辑/删除、上架/停售 |
| 班级管理 | 排班（关联课程与教师）、报名进度条、状态管理 |
| 教师管理 | 教师档案、科目/状态筛选、在职/离职 |
| 学生管理 | 学员档案、班级关联、家长联系方式、在读/休学/已结课 |
| 缴费管理 | 收入统计、缴费登记（选学员自动带出班级与价格）、确认到账、作废 |
| 新闻中心 | 机构资讯门户：置顶头条、分类筛选、新闻详情（自动累计阅读量）、发布/编辑/删除 |
| 课件资源 | 资源库卡片：课件 PPT / 教学视频 / 习题册 / 素材包四类，按课程筛选、模拟下载计数、上传/编辑/删除 |
| 用户管理 | **仅超级管理员可见**：系统账号增删改、角色分配、启用/禁用、重置密码 |
| 个人信息 | 资料维护、修改密码 |
| 系统设置 | 机构信息、业务开关、一键重置演示数据 |

### 技术说明

- 演示数据硬编码在 `web/js/data.js`，首次加载后持久化于浏览器 localStorage，增删改操作刷新不丢失；
- 旧版本数据自动迁移（`meta.version` 比对）：升级到 v0.2 后会自动补齐多用户、新闻、课件资源数据，保留已有修改；
- 可在「系统设置 → 演示数据管理」中一键重置；
- 通用组件（侧边栏布局、模态框、Toast、确认框、徽章、头像、权限过滤）由 `web/js/common.js` 提供；
- 数据模型与业务校验（如：课程被班级引用时不可删除）为后续接入真实后端预留。
