## 背景

v0.4 已完成四类身份登录与服务端门禁，但教师 / 学员 / 家长三端只有**只读工作台**：能看到学籍、班级、已缴金额，不能提交作业、不能看课表、不能请假、看不到缴费明细。业务侧已明确提出 7 项诉求：作业提交、课表查看、缴费详情、课程查看、学生请假、教师审批、授课查看。

这 7 项并非 7 个独立页面，而是 4 条闭环，且存在两个前置卡点：

1. **课次不存在**：`classes.schedule` 是自由文本（「周六 09:00-10:30」），无法生成具体日期的课次，作业 / 请假 / 考勤没有挂载点；
2. **应收不存在**：`payments` 只是收款流水，没有「应缴」概念，家长端「缴费详情」说不清欠费。

因此本 issue 按 **课次 → 作业 / 请假 → 缴费详情** 的顺序交付 P0 最小闭环。

## 目标（可衡量）

- [ ] 学员 / 家长 / 教师三端均可按周查看课表，数据来自同一份课次，取消 / 调课可见
- [ ] 学员可在线提交作业（文本 + 附件），教师可批改 / 退回，提交率可统计
- [ ] 学员与家长可发起请假，教师可审批，审批通过后考勤自动记为「请假」
- [ ] 家长可查看孩子的应缴 / 已缴 / 欠费明细，与后台缴费数据逐笔一致
- [ ] 所有跨身份 / 跨班级访问返回 403，且有自动化测试覆盖
- [ ] 三端页面在 390px 宽度下可用，高频动作 ≤ 2 步

## 范围

**本期做**

- 结构化排课：`class_schedules` 规则 + `class_sessions` 课次
- 作业：布置 / 提交 / 批改 / 退回 / 提交率
- 请假：申请 / 撤销 / 审批 / 与考勤联动
- 考勤：按课次点名 / 补录（仅教师端）
- 家长缴费详情：账单（过渡口径）+ 流水 + 汇总
- 站内通知基础能力 + 家长多孩切换

**本期不做**（另开 issue）

- 在线支付、微信模板消息、发票 / 退费、课程评价、阶段报告 PDF
- 题库 / 自动判题 / 直播 / IM
- 课时包扣减（`enrollments`，见《01》§11.1）与多校区

## 任务分解

> 勾选框即子任务；每个子任务完成后补一句验收结论。估算为「开发 + 自测」，不含联调返工。

### E1 课次与排课（前置，6 人日）

- [ ] **T1.1 数据模型与迁移**（1d）
  - 新增 `class_schedules`（weekday / startTime / endTime / effectiveFrom / effectiveTo / classroom）
  - 新增 `class_sessions`（code `SK001`、classId、teacherId、sessionDate、startTime、endTime、classroom、topic、status）
  - 唯一键 `(classId, sessionDate, startTime)`；索引 `(teacherId, sessionDate)`、`(classId, sessionDate)`
  - 验收：`pytest` 建表 / 唯一键冲突用例通过；旧库可平滑升级
- [ ] **T1.2 排课规则维护**（1d）
  - 后台班级页支持多条规则（周一/三/五）、生效区间、教室；`endTime > startTime` 校验
  - 验收：一个班配 3 条规则后课次数量 = 周次数 × 周数
- [ ] **T1.3 课次生成与例外**（1.5d）
  - 按规则幂等生成课次（重复执行不重复插入）；跳过节假日配置
  - 支持「取消课次」「调课」（原课次标记 + 新时间），已上课课次不可改
  - 验收：改规则只影响未来未上课课次；已上课课次不变
- [ ] **T1.4 三端课表接口**（1d）
  - `GET /portal/student/timetable`、`GET /portal/parent/{studentId}/timetable`、`GET /portal/teacher/timetable`、`GET /portal/teacher/sessions/{id}`
  - 服务端按身份解析数据范围；越权 403
  - 验收：JS001 只返回 BJ002 / BJ003 课次
- [ ] **T1.5 三端课表页面**（1d）
  - 周视图（默认）/ 月视图；课次卡含时间、班级、课程、教师、教室、状态
  - 已取消置灰、调课双行、已请假标记；移动端可用
  - 验收：390px 无横向滚动；空状态文案正确
- [ ] **T1.6 存量数据迁移**（0.5d）
  - 「排课向导」解析「周六 09:00-10:30」为规则；解析失败转人工补录，不阻塞上线
  - 验收：种子数据 6 个班级全部生成课次

### E2 作业闭环（7 人日）

- [ ] **T2.1 作业与提交表 + 附件能力**（1.5d）
  - `homeworks`、`homework_submissions`、`files`；附件白名单与 20MB 上限
  - 上传 / 鉴权下载 `/files/{id}`，非归属人 403，目录不可静态直出
  - 验收：猜 URL 无法下载他人附件
- [ ] **T2.2 教师布置 / 编辑 / 截止**（1.5d）
  - 字段：标题、说明、附件、关联课次（默认本节）、截止时间、允许迟交、满分
  - 已发布可编辑；有提交不可删除（409），只能归档
  - 验收：截止时间早于发布时间返回 422
- [ ] **T2.3 学员提交 / 草稿 / 撤回**（1.5d）
  - 截止前可反复覆盖（保留最后一版 + 版本号）；迟交按 `allowLate` 打标
  - 截止前可撤回；已批改不可改
  - 验收：重复提交幂等；截止后提交 409
- [ ] **T2.4 批改 / 退回**（1.5d）
  - 分数 0–100 + 评语；退回必填理由，原成绩作废并留痕
  - 验收：退回后学员可重交，状态与成绩正确
- [ ] **T2.5 提交率统计**（0.5d）
  - 已交 / 未交 / 已批三页签，未交名单；提交率 = 已交人数 / 应交人数
  - 验收：统计数与名单一致
- [ ] **T2.6 作业通知**（0.5d）
  - 发布、截止前 24h、批改、退回四个触点写站内信
  - 验收：学员与家长都能收到且未读角标正确

### E3 请假与考勤（5 人日）

- [ ] **T3.1 请假表 + 课次关联**（1d）
  - `leave_requests`（`QJ001`）+ `leave_request_sessions`；`(studentId, sessionId)` 有效记录唯一
  - 验收：同一课次重复申请返回 409
- [ ] **T3.2 学员 / 家长发起与撤销**（1.5d）
  - 按课次多选、类型、事由（≥ 5 字）、可选病历附件；`applicantType` 区分 student / parent
  - 仅未来课次可申请；待审批可撤销
  - 验收：家长只能给关联孩子提交；撤销后状态回「已撤销」
- [ ] **T3.3 教师审批**（1d）
  - 待办按上课时间升序；通过 / 驳回（驳回必填理由 ≤ 100 字）；已审批 409
  - 验收：教师 A 审批教师 B 班级返回 403
- [ ] **T3.4 点名与补录**（1d）
  - 默认全出勤，点异常；请假学员自动预填且不可改；课后 7 天内可补录（需备注）
  - 验收：重复点名幂等；补录留痕
- [ ] **T3.5 请假 → 考勤联动 + 通知**（0.5d）
  - 通过即写 `attendance.status = 请假`；撤销 / 驳回回退未点名
  - 通知学员 + 家长；课表打「已请假」
  - 验收：三处状态一致

### E4 家长缴费详情（2 人日）✅ 2026-10-22 已实现（`tests/test_payments_portal.py` 7 项断言）

- [x] **T4.1 账单口径与接口**（1d）
  - `bills`（`ZD001`，报名时按课程价自动生成）+ `payments.billId`
  - `GET /portal/parent/{studentId}/payments`、`GET /portal/student/payments`
  - 口径：应缴 = Σ 有效账单；已缴 = Σ 已支付流水；欠费 = 差额（≥ 0）
  - 验收：汇总与后台 `/payments/stats` 差额为 0
- [x] **T4.2 家长 / 学员页面**（0.5d）
  - 汇总卡 + 账单列表 + 流水明细；待确认 / 已作废 / 已退款区分展示
  - 验收：待确认不计入已缴；作废后欠费回滚
- [x] **T4.3 历史数据兼容**（0.5d）
  - 无 `billId` 的历史流水归入「历史流水」，不参与欠费计算
  - 验收：老数据不产生虚假欠费

### E5 通知与多孩（1 人日）

## 风险

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 排课规则解析存量文本失败 | 课次缺失 | 提供向导 + 手工补录，不阻塞上线 |
| 请假与考勤双写不一致 | 家长投诉 | 单事务 + 补偿校验脚本 |
| 附件直链泄露 | 隐私事故 | 鉴权下载 + 目录不在静态根 |
| 范围蔓延（支付 / 微信 / 课时包） | 拖期 | 严格按「本期不做」清单拒绝 |
